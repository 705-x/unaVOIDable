This function is used to make sure enemies spawn somewhere near the player, not at random somewhere in the map.

Parameters
playerPosPassed as global position, which this function later converts to tiles.
radiusExpressed in tiles, radius of the area in which the entities can spawn.
occupiedTilesDetermines which tiles are within the radius in perspective to the player, from which a random tile is chosen to spawn an enemy onto.
